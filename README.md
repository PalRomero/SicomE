# ⚡ SICOM Eléctrica

Página web de venta de materiales eléctricos en Santa Fe y Santo Tomé.

## 🧠 Descripción

Este proyecto es una landing page orientada a la venta de productos eléctricos mediante contacto directo por WhatsApp.

Incluye:

- Catálogo de productos
- Categorías eléctricas
- Botones de consulta directa
- SEO básico local
- Diseño responsive

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- GitHub Pages (hosting)

## 📦 Productos actuales

- Disyuntor diferencial 40A
- Llave térmica 20A
- Cable 2.5 mm²

## 🚀 Cómo usar

1. Clonar o descargar el repositorio
2. Abrir `index.html` en el navegador
3. Publicar mediante GitHub Pages
